# 📊 RetailPulse Analytics

### Retail Sales & Business Intelligence Dashboard

An interactive **Power BI sales analytics project** built to analyze retail transactions, customer behavior, product performance, promotions, and geographic trends.

The project transforms raw Excel data into an interactive dashboard using **Power BI, DAX, Power Query, and data modeling**.

---

## 📌 Project Snapshot

| Metric | Value |
|---|---:|
| 🧾 Transactions | **3,510** |
| 👥 Customers | **50** |
| 🛍️ Products | **30** |
| 📦 Units Sold | **7,125** |
| 🎯 Promotions | **5** |
| 📅 Data Period | **2020–2024** |

## 🎯 Objectives

- Analyze overall **sales, profit, and quantity performance**
- Identify **top and bottom-performing products**
- Analyze **customer-level performance**
- Evaluate **promotional campaign performance**
- Understand **geographic sales distribution**
- Build an interactive dashboard for **data-driven decision making**

---

## 🛠️ Tech Stack

- **Power BI** – Dashboard & visualization
- **DAX** – Calculated measures and analytical metrics
- **Power Query** – Data cleaning & transformation
- **Excel** – Source dataset
- **Git/GitHub** – Version control

## 💡 Business Value

The dashboard enables users to quickly identify:

- High and low-performing products
- Key customers contributing to sales
- Strong-performing geographic regions
- Sales and quantity patterns
- Promotional performance

This reduces the effort required to analyze **3,510 individual transactions** and provides a centralized view of retail performance.

## ▶️ How to Use

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/RetailPulse-Analytics.git
```

2. Open `Sales Data Analysis Proj1.pbix` in **Power BI Desktop**.

3. If required, update the data source path to `Store Data.xlsx`.

4. Use the dashboard filters and slicers to explore the analysis.
